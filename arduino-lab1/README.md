# Лабораторная работа №1. Arduino UNO: светодиоды, кнопки, потенциометры

Дисциплина «Программирование микропроцессоров». Скетчи к отчёту.

| Папка | Задание |
|---|---|
| `task01_blink` | 1. Мигание светодиодом на выводе 13 (этот же скетч используется в задании 2) |
| `task03_button_hold` | 3. Светодиод горит, пока кнопка зажата |
| `task04_button_toggle` | 4. Переключение светодиода по нажатию кнопки |
| `task05_potentiometer_brightness` | 5. Яркость светодиода потенциометром |
| `task06_brightness_freeze` | 6. Фиксация яркости при удержании кнопки |
| `task07a_traffic_delay` | 7А. Светофор на задержках |
| `task07b_traffic_for` | 7Б. Светофор на циклах for |
| `task08_traffic_button` | 8. Светофор по кнопке |
| `task09_rgb_traffic` | 9. Светофор на RGB-светодиоде |
| `task10_rgb_potentiometer_hsv` | 10. Смена цвета потенциометром (HSV) |
| `task11_rgb_encoder` | 11*. Управление цветом энкодером |

## Подключение выводов

- Светодиод (задания 1–4): D13
- Светодиод с ШИМ (задания 5–6): D9
- Кнопка (задания 3, 4, 6, 8): D2, режим `INPUT_PULLUP`
- Потенциометр: A0
- Светофор (задания 7, 8): зелёный D8, жёлтый D7, красный D6
- RGB-светодиод (общий катод, задания 9–11): R D9, G D10, B D11
- Энкодер (задание 11): CLK D2, DT D3, SW D4

Скорость монитора порта: 9600 бод.
